# חסלט מְחַסֶּלֶת 🥬 · המשחק

> יד אחת. צרור עלי סלק. אפס סובלנות לאויבינו ומבקשי רעתנו.

משחק פרסומי-סאטירי לחסלט: יד שמחזיקה צרור **עלי סלק** (סילקה) ומחסלת איתו את האויבים
הקלאסיים – נסראללה, חמינאי, סינוואר, הנייה, מוחמד דף, אבו עוביידה, אל-חות׳י, סולימאני,
אחמדינג׳אד, נעים קאסם – ובבונוס גם המן הרשע ופרעה. עלה-עלה.

## 🎮 שלושה מצבי משחק

### מצב חיסול (הכה-בחפרפרת)
- 9 בורות בשדה חסה. האויבים צצים – ואתם מנחיתים עליהם עלה. **60 שניות.**
- הקושי עולה: צצים מהר יותר, נשארים פחות, ועד 3 בו-זמנית.
- **קומבו**: 3 פגיעות רצופות = מכפיל, עד ×5. פגיעה מהירה (תוך 0.4 שנ׳) = בונוס.
- **פתיון**: מדי פעם צצה שקית חסלט. מי שמחסל אותה מפסיד 150 נקודות ומקבל נזיפה.
- דמויות בונוס (המן, פרעה) שוות 250.

### מצב מדף
- האויב **מרחף בזירה**. למטה – **המדף שלכם** עם מוצרי חסלט.
- רק לחיצה על **עלי הסלק** מסלקת אותו (בפוף של עשן: "סוּלַק!").
- לחיצה על מוצר אחר = האויב צוחק, תגובה מצחיקה בבועה ("כוסברה לא מחסלת. היא רק מפלגת את העם."),
  ואתם מפסידים שנייה.
- **שלבים**: מתחילים עם כוסברה / פטרוזיליה / עלי סלק. כל 4 סילוקים עולים שלב: נכנס מוצר
  (חסה, רוקט, תרד, נענע, שמיר, בזיליקום, קייל, עלי בייבי, בצל ירוק, סלרי, סלט כרוב),
  הזמן מתקצר, משלב 6 התוויות נעלמות, ומשלב 8 המדף מתערבב בכל טעות.
- 3 חיים (🥬). אויב שברח = חיים אחד פחות.

### מצב ירי
- האויבים **צונחים במצנחים** מלמעלה. אתם למטה עם צרור עלי הסלק – גלוי כל הזמן.
- לחיצה על אויב משגרת **עלה** מהצרור. פגיעה = חיסול באוויר, קומבו כמו במצב חיסול.
- אויב שנוחת על הקרקע = חיים אחד פחות (3 חיים). הגלים מתקדמים כל 20 שניות: יותר צונחים, מהר יותר.
- **שקית חסלט** שצונחת: לא יורים עליה (−150). מזיזים את היד מתחתיה ותופסים אותה (+100).

### ועוד
- **אלבום המחוסלים** – כל דמות, כמה פעמים חוסלה (נשמר בדפדפן).
- **שיתוף** – Web Share בנייד, וואטסאפ בדסקטופ. טקסט שיתוף שונה לכל מצב.
- **דרגות** לפי ניקוד: עלה נובט → צרור מבטיח → סלק מנוסה → אלוף הסלט → מחסל-על ירוק.
- אפקטי קול מסונתזים (Web Audio, בלי קבצים) עם כפתור השתקה. ההשתקה נשמרת.
- RTL, נייד-ראשון, בלי תלויות, בלי build. מתארח חינם ב-GitHub Pages.

js/products.js      · המוצרים: שקיות חסלט עם עלים פרוצדורליים לכל מוצר + התגובות ללחיצה שגויה
js/audio.js         · אפקטי קול מסונתזים
js/fx.js            · היד שעוקבת אחרי הסמן, עלים עפים, פוף, טקסט מרחף, חותמת

js/shelf.js         · מצב מדף
js/shoot.js         · מצב ירי (צניחה, ירי עלים, תפיסת שקיות)
js/main.js          · תפריט, תוצאה, אלבום, שיתוף, אחסון מקומי

## ✏️ עריכה

**להוסיף אויב** – מוסיפים אובייקט ל-`ENEMIES` ב-`js/characters.js`. הכל מוגדר בפרמטרים:
`skin`, `beard` (full / long / trim / stubble / goatee), `hair` (short / receding / combed), `headgear`
(turban / wrap / keffiyeh / haman / nemes), `glasses` (round / thin / square), `clothes`
(robe / suit / military / shirt / jacket / royal / pharaoh), `mouth`, `quip`, `weight`, `points`.

**להוסיף מוצר למדף** – מוסיפים ל-`PRODUCTS` ב-`js/products.js` עם `leaves` (סוג העלים) ורשימת `wrong`
(התגובות המצחיקות). סדר הרשימה = סדר הכניסה לשלבים.

**לכוונן קושי** – `levelCfg()` ב-`js/shelf.js` (כמות מוצרים, זמן, תוויות, ערבוב), `tick()`/`spawn()` ב-`js/whack.js`, ו-`RAMP`/`WAVE_MS`/`spawn()` ב-`js/shoot.js`.

**להחליף לוגו** – מחליפים את `assets/logo.jpg`. אין צורך לגעת בקוד.

## 🧪 בדיקה מקומית

```bash
python -m http.server 8642
```
ואז `http://localhost:8642/`. (השקיות והדמויות הן SVG שנוצר בזמן ריצה – חייבים שרת, לא `file://`.)

## 📝 הערות

- כל הדמויות הן **קריקטורות SVG מקוריות** שנבנו בקוד – אין תמונות, אין זכויות יוצרים של צלמים.
  אם רוצים להחליף לתמונות/קריקטורות מעוצבות, כל דמות מתרנדרת דרך `Chars.enemySvg(e)` – נקודת החלפה אחת.
- הצבעים, הפונט והכרטיסים תואמים את הפרויקט הקודם של חסלט ("שיבוץ לכיבוד").
- אין אנליטיקס בקוד. אפשר להוסיף GTM/GA ב-`<head>` כמו בפרויקט הקודם.
